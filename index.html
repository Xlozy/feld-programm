    Einstellungen

    GitHub-Sync

    Daten liegen als JSON in einem separaten GitHub-Repository. Token erstellen unter github.com/settings/tokens — «Contents: Read and write» auf das Daten-Repo genügt.

    Knotenpunkte

    Knotenpunkte werden in der Kartei vergeben. Umbenennen, zuweisen, zusammenführen und löschen: in der Spalte Knotenpunkte einen auswählen, dann ⋯ → Bearbeiten. Hier lassen sich Knotenpunkte auf Vorrat anlegen.

    Export / Import

    Export als Sicherung oder zur Übertragung. Import fügt Daten aus einer Datei zusammen (gleiche ID = neuere Version gewinnt).
